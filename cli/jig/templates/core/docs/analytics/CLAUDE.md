# docs/analytics

Analytics reports and product data.

## Purpose
Reports, metrics, and data analysis. Product documents live in docs/product/,
plans in docs/planning/; here go measurement results and their analysis.

## Local rules
- One report — one file, kebab-case; include a date or period in the name.
- Build out structure as needed; do not create empty folders in advance.

## How to keep it
There is no starting structure — the first report sets it. Raw data and its
analysis go in separate files.
