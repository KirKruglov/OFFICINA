# docs/planning

Planning of product evolution and development.

## Purpose
Roadmaps and development plans. BACKLOG.md is the single backlog: the keeper of
tasks between releases and of technical debt. Plans for a specific release live
in separate files.

## Local rules
- One plan — one file, kebab-case.
- Convert relative dates to absolute ones.
- The backlog is the single source between releases; a release-ready item moves to the release plan.

## How to keep it
BACKLOG.md — follow the template inside the file itself. A release plan is a
separate file in release-plan/ (the folder appears in full projects).
