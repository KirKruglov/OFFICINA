# Phrasing bar for the handoff block

Weak → strong pairs on fragments. They show item density; section makeup is in
the template, inclusion rules are in `SKILL.md`.

## 1. Done

**Weak**

- Worked on input validation

**Strong**

- Empty input is rejected before write; error copy is agreed

Why: records the decision taken, not the fact that "something was done".

## 2. In progress

**Weak**

- Finishing the report

**Strong**

- cli/report.py — row table assembles, totals row is not printed

Why: shows where work stopped, not only the topic.

## 3. Context for the next session

**Weak**

Continue in the same vein.

**Strong**

Close the argument parse first; empty-input checks go after it.

Why: hands over an order that the lists above do not carry.
