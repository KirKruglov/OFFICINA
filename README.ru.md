## Зачем OFFICINA

OFFICINA — мастерская для работы с AI-инструментами в разработке продуктов. В основе — **метод**:
как выстроить работу с AI-ассистентом так, чтобы она была предсказуемой и воспроизводимой. Вокруг
него — скиллы, субагенты, CLI и конфиги, готовые к переиспользованию.

- **Сначала метод.** Переиспользуемые правила и руководства — стиль письма, авторинг CLI, авторинг
  скиллов и субагентов, инженерия циклов — каждое самодостаточно и читается отдельно.
- **Переносимые скиллы, ядро на Claude Code.** Скиллы не привязаны к одному инструменту — работают в
  Claude Code и совместимых с ним средах. Субагенты и настройки заточены под Claude Code. И то, и
  другое отобрано вручную, а не выгружено скопом.
- **Окружение вокруг ядра.** VS Code как прикладной раздел, поддерживающий ядро, а не заглавие.

## Для кого

- **Работаете с AI-ассистентом и хотите системности** — метод, а не разовые промпты.
- **Пишете свои скиллы, субагентов, CLI** — берёте выверенные паттерны и руководства.
- **Настраиваете рабочее окружение** под AI-разработку на macOS.

Если ищете plug-and-play дистрибутив «поставил и забыл» — это не он: OFFICINA про метод и осознанный
отбор, а не про готовую сборку под ключ.

## Как устроен метод

Отправная точка — вопрос «чем решать задачу»:

- Детерминированное действие, модель не нужна — **CLI** (например, [`jig`](cli/jig/) разворачивает новый репозиторий одной командой)
- Нужно понять контекст и решить по ситуации — **скилл**
- Изолированная подзадача или роль-персона — **субагент**
- Повторяющийся цикл по расписанию — **loop**

Дальше — соответствующий гайд в [`methodology/`](methodology/): структура, конвенции, чеклист перед
деплоем. Метод общий, артефакт переносится между проектами.

[`jig`](cli/jig/) — пример метода, ставшего инструментом: одной командой он разворачивает ту самую
структуру доков и настройку под Claude, которые описывают гайды в [`methodology/`](methodology/).

## Быстрый старт

Требуется **macOS**. Клонируйте репозиторий и откройте раздел под вашу задачу — у каждого свой
README и, где уместно, установщик в одну команду в [`install/`](install/):

```bash
git clone https://github.com/KirKruglov/OFFICINA.git
cd OFFICINA
```

Первый готовый установщик настраивает окружение VS Code:

```bash
./install/vscode.sh   # настройки, горячие клавиши, шрифт MesloLGS Nerd Font, курированные расширения
```

## Философия

- **Правильный инструмент под задачу.** Детерминированное уходит в скрипт, решения по контексту —
  модели. Лишняя модель в цикле добавляет стоимость и неопределённость.
- **Надёжность держится на ограничениях.** Систему держат границы, бюджеты и проверки. В автономном
  цикле обязателен тот, кто способен сказать «нет».
- **Знание закрепляется в артефакте.** Гайд, скилл или субагент переиспользуются; выведенное однажды
  не выводится каждый раз заново.
- **Отбор вручную.** В репозиторий попадает проверенное на практике и осознанно выбранное.
